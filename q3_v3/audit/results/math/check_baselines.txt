========================================================================
  {}                       -> vae_k6.npz
  {'hidden': [64]}         -> vae_h64_k6_b0.01_e4000_s0.npz

  {'hidden': ()}           -> vae_h_k6_b0.01_e4000_s0.npz
  {'beta': 1e-05}          -> vae_h64_k6_b1e-05_e4000_s0.npz
  {'beta': 0.01}           -> vae_k6.npz
  {'epochs': 4000.0}       -> vae_k6.npz
  {'latent': 3}            -> vae_h64_k3_b0.01_e4000_s0.npz
  hidden=64 (int)          -> TypeError: 'int' object is not iterable
  NOTE: baselines.vae_model mirrors this logic exactly (copied from baselines.py:65-69)
  NOTE: hidden=[64] (a list) is the default config but misses the default cache and trains + writes a second file vae_h64_k6_b0.01_e4000_s0.npz into baseline_cache/
  NOTE: vae_model(... cache=True) for any non-default config writes into q3_v3/baseline_cache/
